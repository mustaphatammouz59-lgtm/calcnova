Quick tips

  • Deg / Rad — trig uses the unit you select; degrees is the default.
  • Ans — recalls the last result, so you can chain calculations.
  • EXP — enter powers of ten: 2 EXP 3 means 2×10³ = 2000.
  • M+ / M− / MR — a memory register, independent of the display.
  • ʸ√x — type the root first: 3 ʸ√ 8 = 2.

How to use it

Build an expression exactly as you would write it: the display shows the expression as you type and a live result underneath. Parentheses group as usual, multiplication is implied where mathematics implies it — 2π and 2(3+4) both work — and pressing = records the calculation in the history and makes the result available through Ans. Function keys such as sin, ln, and √ insert the function and an opening parenthesis; close it yourself or let the calculator close it when you press =. Postfix keys act on the value just before them: x² squares, n! takes the factorial, % divides by 100, and 1/x inverts.

Keyboard shortcuts

Digits and . + − * / type directly; ^ is power, % is percent, and ( ) group. Enter or = evaluates, Backspace deletes the last entry, and Escape clears. The calculator keeps double precision internally — roughly 15 significant digits — and displays 12, switching to exponential notation outside that comfortable range, so a result like 0.1 + 0.2 shows the honest 0.3 rather than a trail of binary rounding dust.
